# WordMaster — сөздер базасының құрылымы

## Файл құрылымы

```
язык приложение/
  index.html              ← қосымша (өзгертпеу керек, барлық логика осында)
  data/
    manifest.json         ← қолжетімді тізімдер (Top 1000 / 2000 / 3000 / 5000 / ML)
    confusing_words.json  ← "Nuance Challenge" үшін мағынасы ұқсас сөз топтары
    words/
      TOP1000.json          ← Top 1000 (A1–A2), қазір 1500 сөз
      B1.json                ← Top 2000 (B1), қазір 1297 сөз
      B2.json                ← Top 3000 (B2), қазір 1287 сөз
      C1.json                ← Top 5000 (C1), қазір 1118 сөз
      ML.json                ← Machine Learning, қазір 827 сөз
```

`index.html` ашылғанда алдымен `data/manifest.json`-ды, содан кейін онда көрсетілген әр тізім файлын (`data/words/*.json`) жүктеп алады. Демек, **сөздерді қосу үшін кодты өзгертудің қажеті жоқ** — тек JSON файлдарын толықтырсаңыз жеткілікті.

**Ескерту:** егер `data/*.json` файлдары қандай да бір себеппен қолжетімсіз болса (мыс. `index.html`-ды double-click арқылы тікелей ашсаңыз), қосымша автоматты түрде өзінің құрастырылған (ендірілген) сөздер көшірмесіне ауысады, сол себепті ешқашан толық бұзылмайды. Бірақ бұл көшірме — JSON файлдарын жаңартқан сайын өзгермейтін статикалық снапшот. **JSON файлдарына енгізген өзгерістерді нақты көру үшін төмендегі "жергілікті сервер" бөлімін пайдаланыңыз.**

## Top-N жүйесі және `rank` өрісі

Әр тізім белгілі бір жиілік диапазонына сәйкес келеді (ағылшын тіліндегі ең жиі қолданылатын сөздер бойынша шамамен бағаланған, дәл корпус деректері емес — бастапқы демо мән ретінде):

| Тізім (code) | Атауы (label)         | Жиілік диапазоны | Файл             |
|---|---|---|---|
| `TOP1000` | Top 1000 (A1–A2) | rank ≈ 1–1000    | `words/TOP1000.json` |
| `B1`      | Top 2000 (B1)    | rank ≈ 1001–2000 | `words/B1.json`      |
| `B2`      | Top 3000 (B2)    | rank ≈ 2001–3000 | `words/B2.json`      |
| `C1`      | Top 5000 (C1)    | rank ≈ 3001–5000 | `words/C1.json`      |
| `ML`      | Machine Learning | ML корпусындағы шартты жиілік (1 = ең негізгі термин) | `words/ML.json` |

Әр сөз объектісінде `rank` (бүтін сан) өрісі бар — сөздің сол тізім ішіндегі жиілік реті. Ол қосымшада квиз бетіндегі белгіде (мыс. "Top 2000 (B1) · #1050") және "Сөздер" тізіміндегі шағын белгіде (мыс. "#1050") көрсетіледі. `rank` міндетті емес — болмаса, белгі жай көрсетілмейді.

## 1. Бар тізімге сөз қосу

Тиісті файлды ашыңыз (мыс. `data/words/B1.json`) және массивке жаңа объект қосыңыз:

```json
{
  "id": "b1_29",
  "word": "persuade",
  "rank": 1400,
  "definition": "To make someone do or believe something by giving them good reasons.",
  "example": "It took a while to ___ her to join the team."
}
```

Талаптар:
- `id` — бүкіл жоба бойынша қайталанбауы керек (префиксті сақтаңыз: `b1_..`, `ml_..`, т.б.).
- `word` — ағылшынша сөз.
- `definition` — ағылшынша анықтама.
- `example` — сөздің орнына `___` (үш сызықша) қойылған сөйлем.
- `rank` — міндетті емес, бірақ бар болса сол тізімнің жиілік диапазонына сай санды пайдаланыңыз (жоғарыдағы кестені қараңыз).

Файлды сақтаңыз, парақты жаңартыңыз (F5, сервер арқылы ашылса) — жаңа сөз автоматты түрде тестке қосылады.

## 2. Жаңа тізім қосу (мыс. Top 10000 немесе жаңа тақырып)

1. `data/words/<АТАУ>.json` файлын жасап, жоғарыдағы форматта сөздер қосыңыз.
2. `data/manifest.json` ішіне жаңа жол қосыңыз:

```json
{ "code": "TOP10000", "label": "Top 10000 (C2)", "short": "10K", "file": "words/TOP10000.json" }
```

`short` — сүзгі батырмасында көрінетін қысқа белгі (мыс. "10K"); болмаса `code` өзі көрсетіледі. Кодты өзгертудің қажеті жоқ — сүзгі жолағында жаңа батырма автоматты пайда болады.

## 3. Бір тізімде сөз саны өте көбейсе (мыс. 500+)

Бір `.json` файл тым үлкен болып кетсе, оны бірнеше бөлікке бөліп, `manifest.json`-да `"file"` орнына тізім беруге болады:

```json
{ "code": "B1", "label": "Top 2000 (B1)", "short": "2K", "files": ["words/B1_1.json", "words/B1_2.json"] }
```

**Ескерту:** қазіргі `index.html` тек `"file"` (жалғыз файл) өрісін оқиды. Егер осы бөлу тәсілін нақты қолданғыңыз келсе, айтыңыз — `index.html`-дың жүктеу логикасына `"files"` тізімін де қолдау қосамын.

## Nuance Challenge (confusing_words.json)

"Тест" бетінің жоғарғы жағында 🎯 **Nuance Challenge** режимі бар — мағынасы жақын сөздердің (мыс. `goal` / `aim` / `target` / `objective`) арасындағы айырмашылықты үйрететін жеке жаттығу. Бұл режим негізгі деңгей сүзгісіне тәуелсіз, өз дерек файлын пайдаланады: `data/confusing_words.json`.

Құрылымы:

```json
{
  "sets": [
    {
      "id": "cw_affect_effect",
      "topic": "affect vs effect",
      "words": [
        {
          "word": "affect",
          "nuance": "Негізгі айырмашылығы — қысқа, ағылшынша түсіндірме.",
          "example": "Loud noise can ___ your ability to concentrate.",
          "whenToUse": "Бұл сөзді қашан қолдану керектігі туралы қысқа ереже."
        },
        { "word": "effect", "nuance": "...", "example": "...", "whenToUse": "..." }
      ]
    }
  ]
}
```

Талаптар:
- Әр `set` — 2-4 сөзден тұратын мағынасы жақын топ.
- `word` — ағылшынша сөз; `example` сөйлемінде сөздің орнына `___` қойылады.
- `nuance` — сол сөздің басқаларынан негізгі айырмашылығы.
- `whenToUse` — сөзді қашан қолдану керектігі туралы қысқа ереже.

Жаттығу барысында әр раундта кездейсоқ бір топ таңдалады, сол топтың бір сөзінің мысал сөйлемі көрсетіледі (сөз орнына бос орын қойылған күйде), пайдаланушы топтағы сөздердің қайсысы сол контекске дәл келетінін таңдайды. Жауап бергеннен кейін топтың барлық сөздері үшін "Айырмашылығы (Nuance)" карточкасы шығады — дұрыс сөз жасыл түспен белгіленеді.

Жаңа топ қосу үшін жай ғана осы файлдың `sets` массивіне жаңа объект қосыңыз — кодты өзгертудің қажеті жоқ. `index.html` бұл файлды да негізгі сөздер сияқты алдымен желіден жүктеуге тырысады, ол мүмкін болмаса (мыс. `file://` арқылы ашылса), ендірілген көшірмесін қолданады.

## Сөздік базасын автоматты кеңейту (`generate_words.py`)

Жоба түбірінде (`index.html`-мен қатар) `generate_words.py` скрипті бар. Ол
`data/words/*.json` файлдарындағы бар сөздерді сақтай отырып, ішіне
ендірілген (қолмен құрастырылған) сөздер банкынан жаңа сөздерді қосады.
Қазіргі жиынтық: TOP1000 — 213, B1 — 208, B2 — 290, C1 — 185, ML — 149,
барлығы 1045 сөз.

**Ескерту:** бұл ортада Oxford 3000/5000 ресми тізімін немесе
wordfreq/NLTK корпусын тікелей жүктеп алу мүмкін болмады (sandbox желісі
сыртқы дерекқорларға тыйым салған). Сондықтан сөздер банкы менің қолыммен
құрастырылған — бірақ шынайы, тексерілген ағылшын сөздері мен анықтамалары.

Қайта іске қосу:

```
python3 generate_words.py
```

Скрипт бос жүрмейді — ол енді бар (немесе бұрын қосылған) сөздерді қайта
қоспайды (сөз бойынша дубликат тексеріледі), сондықтан оны бірнеше рет
іске қосу қауіпсіз.

Келешекте нақты жиілік тізімі қолда болса, оны
`data/words/external_<CODE>.csv` (бағандар: `word,definition,example`)
етіп сақтаңыз — скрипт оны автоматты түрде таниды және хэндкод банкінің
орнына соны пайдаланады (мыс. `data/words/external_B2.csv`).

## Жергілікті серверде тексеру (JSON өзгерістерін көру үшін)

Қосымша `data/*.json` файлдары жоқ кезде де жұмыс істейді (жоғарыдағы ендірілген көшірме арқылы), бірақ ол көшірме сіз JSON файлдарына енгізген жаңа өзгерістерді автоматты көрсетпейді. JSON-ды өңдеп, нәтижесін бірден көру үшін осы папкада (`язык приложение`) кішкентай жергілікті сервер жіберіңіз:

```
python -m http.server 8000
```

Содан кейін браузерде `http://localhost:8000/index.html` адресін ашыңыз. Телефоннан тексеру үшін компьютер мен телефон бір Wi-Fi желісінде болуы керек — сол кезде телефоннан компьютердің жергілікті IP мекенжайын (мыс. `http://192.168.1.5:8000/index.html`) ашуға болады.

Тұрақты шешім үшін қосымшаны GitHub Pages, Netlify немесе ұқсас тегін хостингке жүктеуге болады — сонда HTTPS арқылы толыққанды PWA ретінде (нағыз "Орнату" сұранысымен) жұмыс істейді.
